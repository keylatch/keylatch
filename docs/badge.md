# "Secured by Keylatch" Badge

Add this badge to your project's README to signal that your AI agent workflow is protected by Keylatch.

## Shields.io (recommended)

```markdown
[![Secured by Keylatch](https://img.shields.io/badge/secured%20by-keylatch-blue)](https://keylatch.dev)
```

## Static SVG (offline-friendly)

Download `assets/badge.svg` from the Keylatch repo and reference it locally:

```markdown
[![Secured by Keylatch](./badge.svg)](https://keylatch.dev)
```
